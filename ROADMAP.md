# Setsmith: roadmap

**Setsmith** is a personal, slimmed-down build of Magic Set Editor 2. It was called "MSE Slim" before the rename. Code comments mark changes from upstream with `Setsmith:`. It's based on
[haganbmj/MagicSetEditor2](https://github.com/haganbmj/MagicSetEditor2) 2.5.6 "(Unofficial)", the
community-maintained version that the M15 template pack is built for. That version is itself a fork of
[twanvl/MagicSetEditor2](https://github.com/twanvl/MagicSetEditor2). GPL v2; this fork stays GPL.

- **Branch:** `slim` (local only, not pushed yet)
- **Remotes:** `upstream` = haganbmj (base), `twanvl` = original upstream (reference only)
- **Goal:** a smaller install and a simpler UI, focused on making Magic cards in the M15 frame and UniVersus cards in the 2026 frame.
- **Related:** `custom-uvs` (the UniVersus web app) borrows feature ideas from MSE. See its `ROADMAP.md`.

| Date | Decision |
|---|---|
| 2026-11-08 | "Slim" means smaller template data plus a simpler UI. The rendering engine is kept as is. |
| 2026-11-08 | Toolchain: MSYS2 (UCRT64) at `D:\msys64`, with CMake, Ninja, wxWidgets 3.2, Boost and Hunspell from pacman. |
| 2026-11-08 | Local only for now. Push to GitHub once it builds. |
| 2026-11-08 | `custom-uvs` stays a web app. The slim MSE stays Magic-only. *(Replaced later the same day by the next row.)* |
| 2026-11-08 | Setsmith gets a 1:1 UniVersus template (2026 frame), for custom proxies, which UVS Games allows. Why: the user wants real-looking UVS cards in the same editor as their Magic cards. It's for personal use only, so the official fonts and extracted symbols are used. Spec: `claude/uvs-template.md`. |
| 2026-11-08 | UVS scope: all card types including Arena (landscape) and B sides. Each face exports as a separate image. A clean base frame comes first; per-set border themes come later. Export uses print-shop bleed by default, with exact size as an option. Each set sets its own footer logo and copyright line. |
| 2026-11-08 | UVS needs two small engine additions, marked `Setsmith:`. Text outlines: UVS names and numbers have a black outline plus an outer outline in the type color, which MSE fonts couldn't draw. Masked layout fix: centered rules text has to wrap around the check number, and MSE checked the mask before centering. Both only change text that uses them, and M15 renders stay byte-identical. |
| 2026-11-08 | UVS frame art is generated by a script (`tools/make-uvs-assets.ps1`), not hand-drawn. Colors and shapes stay editable in one place, and every piece is drawn at 2x for print. |
| 2026-11-08 | UVS resource symbols come from the How to Play guide (page 21), where they are vector art, rendered at 1200 dpi. Why: uvsultra's icons are only 16 px and card scans are about 80 px. The guide only shows Air and Water attuned, so the other 11 attuned symbols are built from the circle art in the same square frame, which matches the attuned symbols on FT01 cards. |
| 2026-11-08 | New name: **Setsmith**. It avoids confusion with MSE2 and keeps "Magic" (a Wizards trademark) out of the name. A web search found no card tool with this name. The GPL license and credit to Twan van Laarhoven and the MSE developers stay. |
| 2026-11-08 | Symbol editor replaced by image upload. Drawing vector symbols is slow and rarely used; a PNG made in any art tool is faster, and the rarity filters still apply. |
| 2026-11-08 | Console replaced by popups. It was a whole tab used only to read warnings. |
| 2026-11-08 | Working docs copied from birb-box: `CLAUDE.md`, `claude/` (file map, session log, QA plan) and the Jello Board (`Jello Board.bat`, port 5179). This roadmap stays the vision and decisions doc. |
| 2026-11-08 | Re-based from twanvl 2.1.2 onto haganbmj 2.5.6. 2.1.2 printed `Variable not set: extra_card` on M15 cards, because the template pack targets 2.5.6. The old work is kept on branch `slim-twanvl`. |
| 2026-11-09 | UVS print sizes are stylesheets: `2026 (bleed)` 819 x 1114, `2026 (exact)` 744 x 1039 and `2026 (MPC)` 822 x 1122, picked in the Style tab. MSE already offers the stylesheet as the per-set and per-card choice, so no new UI was needed. `bleed` is split into `bleed_x` and `bleed_y`, because MPC's template is not the same bleed on every side. More printers are new stylesheet headers only. |
| 2026-11-09 | New look, decided with the user: dark "workshop" theme (charcoal, card art pops), logo-gold accent, Figtree UI font, no animations or anything that slows the app. Cards tab: big card preview, slim list, small notes box. List rows get a color stripe: type color for UVS, card color for Magic (WUBRG, gold multicolor, gray colorless, brown land). Soft dark vignette with a drop shadow behind the card. New flat icons drawn by a script. Welcome window: two big game buttons (New Magic set, New UniVersus set, each with a sample card) above recent-set tiles with thumbnails and a game tag. Edit fields go dark too, with a gold focus outline. Title bar and menus stay native (wxWidgets 3.2 can't recolor them). Built in stages, each checked and screenshotted. |
| 2026-11-09 | Setsmith is its own app, built on Magic Set Editor 2 with credit (About, README, bundled README, `UPSTREAM-CHANGES.md`). User-visible text no longer says MSE. Internal identifiers stay (`.mse-*` extensions, package names, `magicseteditor.exe` dependency, `installer group` and `apprentice_code` keys), because templates and old sets use them. The settings file is now `setsmith.config`. The version number stays 2.5.6, because templates check it. |
| 2026-11-09 | Stripped, after the user approved an audit: update checker and installer, statistics graph, version control, Magic Workstation / Apprentice / MTG Editor / MSE1 / HTML formats, Directories preferences page, Help Index and Website items, non-English locales, macOS and Visual Studio files, upstream release script and tests. Kept: printing and the spell checker. Old `version_control` keys are read and ignored so existing sets load clean. |
| 2026-11-09 | No Masterpiece cards on the Magic side (rarity choice, set code, set symbol, style option). Patched into the copied pack by `make-slim-data.ps1`, since the pack is not in this repo. |
| 2026-11-09 | New icons: `app.ico` is a card with a gold diamond, `set.ico` is stacked cards, both drawn by `tools/make-icon.ps1`. |

## Phase 1: Slim data (667 MB -> 180 MB) — done 2026-11-08

`build/data` is now a real folder (no longer a link to the full pack), built by
`tools/make-slim-data.ps1`. Rerun the script after a clean build:

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-slim-data.ps1
```

Frames kept: **M15**, **M15 planeswalkers**, **M15 tokens**. The script follows declared dependencies and
copies 11 packages (180 MB, including the English spell-check dictionary):
